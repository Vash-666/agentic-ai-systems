## Objective
Create a simple, at-a-glance project health dashboard that shows current state, progress, quality, and risks for all active projects.

## Background
**Current State:**
- Project health scattered across multiple files
- Hard to answer "how are we doing?"
- No unified view of progress and risks
- Stakeholders (Rohit) can't quickly assess status

**Desired State:**
- Single dashboard shows all key metrics
- Updated automatically or with minimal effort
- Clear signals: green/yellow/red
- Easy for anyone to understand project health

## Risks & Mitigations
**Risk:** Dashboard gets stale  
**Mitigation:** Weekly sync includes dashboard update, assign owner

**Risk:** Dashboard becomes vanity metrics  
**Mitigation:** Focus on actionable insights, not just pretty numbers

**Risk:** Automation breaks  
**Mitigation:** Manual fallback always available

## Metrics to Track
- Dashboard freshness (time since last update)
- Dashboard usage (how often referenced)
- Time to understand project health (stakeholder survey)
- Accuracy of health indicators (do they predict issues?)

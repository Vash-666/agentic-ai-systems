## Semantic Versioning

We use **SemVer** (MAJOR.MINOR.PATCH):

| Level | When to Bump | Example |
|-------|--------------|---------|
| **MAJOR** | Breaking changes, architectural shifts | 1.x → 2.0 |
| **MINOR** | New features, agents, capabilities | x.1 → x.2 |
| **PATCH** | Bug fixes, optimizations, docs | x.x.1 → x.x.2 |

## Technical Implementation

### Stack
- **Framework:** Next.js 14 + TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Custom SVG (primordial symbols)
- **AI Element:** Canvas/WebGL subtle reactive orb

### Typography
- **Headings:** Playfair Display or Cormorant Garamond
- **Body:** Inter or Satoshi
- **Accent:** Italic for poetic moments

### Animation Principles
- Slow, intentional transitions
- Scroll-triggered reveals
- Gentle parallax
- No jarring movements
- Breathing room between animations

### Responsive
- Mobile: Stacked sections, simplified animations
- Tablet: Adjusted spacing
- Desktop: Full immersive experience

# website-creator — Skill Definition

**Version:** 3.0
**Purpose:** Automated website creation workflow

---

## 1. Requirement Gathering

Collect client requirements for the website project.

## 2. Design Mockup

Create visual design mockups based on requirements.

## 3. Content Drafting

Draft initial content for all pages.

## 4. Component Selection

Select UI components and libraries.

## 5. Development

Build the website using selected stack.

## 6. Responsive Testing

Test across devices and screen sizes.

## 7. Performance Optimization

Optimize loading speed and assets.

## 8. SEO Setup

Configure meta tags, sitemap, and structured data.

## 9. Deployment

Deploy to hosting platform and verify.

---

*End of skill definition.*

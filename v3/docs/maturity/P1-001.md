## What Was Wrong

`quality-score.sh` emitted errors at end of execution:
```
./scripts/quality-score.sh: line 115: scores[-1]: unbound variable
./scripts/quality-score.sh: line 115: scores: bad array subscript
```

Root cause: Bash negative array index `scores[-1]` unsupported on macOS bash 3.2.

## What Was Changed

### scripts/quality-score.sh — calculate_trend()

| Line | Before | After |
|------|--------|-------|
| 115 | `local first="${scores[-1]}"` | `local first="${scores[0]}"` |
| 116 | `local last="${scores[0]}"` | `local last="${scores[${#scores[@]}-1]}"` |

**Logic fix:** First element is oldest (index 0), last element is newest (index `${#scores[@]}-1`). Previously reversed.

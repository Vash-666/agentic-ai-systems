## What Was Wrong

`v3/state/state.db` (36K, 32 checkpoints) had **no automated backup**. Single point of failure — corruption or accidental deletion would lose all checkpoint history.

## What Was Changed

### 1. Created scripts/backup-state.sh

| Feature | Implementation |
|---------|---------------|
| **Source** | `v3/state/state.db` |
| **Destination** | `v3/backups/state-YYYYMMSS-HHMMSS.db` |
| **Integrity check** | `sqlite3 PRAGMA integrity_check` on backup |
| **Rotation** | Keeps last 30 backups, deletes oldest |
| **Logging** | `v3/logs/backup-state.log` |
| **Error handling** | `set -euo pipefail`, exits 1 on failure |

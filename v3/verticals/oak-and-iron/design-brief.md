---

## Key Interactions

### Desktop
- Smooth scroll to sections
- Hover effects on buttons (color shift)
- Sticky navigation
- Parallax on hero image (subtle)

### Mobile
- Hamburger menu
- Stacked sections
- Touch-friendly buttons (min 44px)
- Collapsible hours table

### Universal
- Loading state for form submit
- Success message on email signup
- Lazy load images below fold

---

## Content Hierarchy

1. **Hero:** Brand name + value prop + CTA
2. **Menu:** What they sell (proof of business)
3. **Location:** How to find them (drives foot traffic)
4. **Story:** Why they're different (emotional connection)
5. **Signup:** Conversion (email capture)

---

## Responsive Breakpoints

| Breakpoint | Width | Adjustments |
|------------|-------|-------------|
| Mobile | < 640px | Single column, hamburger nav |
| Tablet | 640-1024px | 2 columns where appropriate |
| Desktop | > 1024px | Full layout, side-by-side sections |
